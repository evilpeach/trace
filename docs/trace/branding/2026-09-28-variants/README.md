# Trace logo directions

Five raster app-icon concepts for Trace's current review workspace and proposed Planner workflow, created on 28 September 2026 with the built-in image generation tool.

Open `index.html` for a comparison with a light/dark canvas, full-size PNG downloads, and 16/24/32 CSS-pixel samples. `comparison.png` captures the dark comparison page. All five concept PNGs are 1254 × 1254 RGBA images with transparency outside the app tile. Exact prompts are in `prompts.json`; dimensions and file sizes are in `asset-metadata.json`.

| Variant | Meaning |
| --- | --- |
| 01 — Trace Path | A copper route forms a T, retaining the existing warm identity. |
| 02 — Dual Horizon | Two connected frames express current and proposed states. |
| 03 — Focus Aperture | The system's whole picture resolves into precise evidence. |
| 04 — Folded Blueprint | A folded T expresses a proposal becoming implementation. |
| 05 — Connected Steps | Problems, plans, and verification form a connected path. |

Selected by the user: **04 — Folded Blueprint**. The [branding guide](../README.md) identifies the approved master and generated app assets. The other directions remain archived alternatives.
