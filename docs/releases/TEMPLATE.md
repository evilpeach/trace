Download **aarch64** for Apple Silicon or **x64** for Intel. Requires macOS 12+.
Open the `.dmg` and drag Trace into Applications; `.app.zip` is an alternative.
Verify downloads with the attached `SHA256SUMS.txt`.

These builds are ad-hoc signed and are not Apple-notarized. After verifying the
download source, use System Settings → Privacy & Security → Open Anyway if macOS
blocks first launch and offers that option. Automatic updates are not configured.

GitHub generates the changes below from the tagged source. See the repository
README for setup requirements and current feature limitations.
