# Trace 0.0.1

First release of Trace, a macOS workspace for understanding and reviewing code changes.

- Explore file summaries, before/after flows, source evidence, and findings.
- Compare local branches and GitHub PRs; prepare review requests for Codex or Claude.
- Keep review decisions, reading progress, and checkpoints separate from immutable reports.
- Use light/dark appearance, configurable shortcuts, and the Folded Blueprint identity.

## Download

Requires macOS 12 or newer. Choose **aarch64** for Apple Silicon (M1 or newer) or
**x64** for Intel. Open the `.dmg` and drag Trace into Applications. The `.app.zip`
is an alternative archive of the same app. `SHA256SUMS.txt` contains checksums for
both architectures and formats.

These builds are **ad-hoc signed, without an Apple Developer ID or notarization**.
macOS may block first launch. After verifying the download source, use **System
Settings → Privacy & Security → Open Anyway** if macOS offers it. This release
does not install an automatic updater.

Local review workflows need Git. GitHub PR lookup needs an authenticated `gh` CLI;
agent handoff needs the selected Codex or Claude CLI. The bundled synthetic
example can be explored without those integrations.

Planner remains a design proposal and is not included in this release.
